# Once

**Live:** https://vishnuvsdevtech.github.io/confetti-once/

Confetti that only fires when it matters. A celebration that happens exactly once per achievement, enforced in localStorage.

**How:** Confetti on every click is wallpaper. Fired once, on something actually finished, it is an event — and the difference is scarcity, not the animation. Pressing again gets an explanation instead of a celebration.

**What it is not:** Reset exists for the demo, and it is the only way to see it twice.
